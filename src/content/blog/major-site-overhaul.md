As you can see my page has had a major overhaul and is now using some state of the art technologies like [react.js](https://facebook.github.io/react/). I have been writing a lot in react lately, and have setup a environment that enables me to write nice react syntax that gets compiled into one single file. This makes loading faster and means I only have to [uglify](https://github.com/mishoo/UglifyJS2) one script. It also concatenates all my libraries and snippets that I want access to globally into one *.lib.js file. 
 
Some of these snippets you will be finding here on my blog, since they can be useful resources for other projects/people. I also plan on writing some tutorials on creating simple react structures that you can re-use, but that is for future me ;)
