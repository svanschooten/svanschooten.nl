My site had not changed since 2018, so it was time for another rebuild.

### The old site

The previous version was built with Vue 2 and Firebase. Every post was fetched from Firestore in the browser, so nothing showed up without JavaScript and posts had no real URLs of their own.

### The new site

This version is built with [Astro](https://astro.build/). Posts and projects are now Markdown files in the repository, and every page is plain static HTML.
