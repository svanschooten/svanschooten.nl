After some time you want to build a new website, using some new interesting things, as is the case right now!
I rebuilt my website from scratch, and though it is not perfect by any means or even done at this point, it it beginning to take shape. While there is no contact form and it is not mobile friendly (yet), I aim to just play with some techniques to improve my site. I also plan to start blogging again, since I have gained quite some experience in the field.

This site is built using [Vue.js](https://vuejs.org/) and the awesome free [Firebase](https://firebase.google.com) as backend to create a completely serverless website! The interaction is done using simple, plain, css since I'm not a front-end designer and, to be honest, I don't really care... But it has to be fun!

Expect more updates and improvements over the coming period. Ciao!
