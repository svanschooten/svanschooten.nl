A small project creating a Java-based task server with a web-based front end to calculate the minimal monster mass for a given error. The minimal monster mass (monster is Dutch for sample) is the minimal mass a sample must have to lie within the specified deviation, based on mixtures and such.

The task server itself was just there for planning and scheduling, as the systems were old and the hardware limited.
