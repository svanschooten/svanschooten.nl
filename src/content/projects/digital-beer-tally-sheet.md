title: "Digital beer tally sheet"
description: "A digital tally system in the house built from an old laptop."
type: "project"
date: 2014-03-15
---

A fun project of creating a tally system with a touchscreen to keep track of the beer stock in the house. Created with a nodeJS server and React for the interactive frontend. Graphs made with d3.js, which consisted of a donut graph, bar charts and scatterplot.

The configuration file contained all the information needed to customize the look and feel, as well as containing the data for the participants and what items are on tally.
